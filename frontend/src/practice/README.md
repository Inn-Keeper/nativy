# Practice Module

UI for the exercise/practice flow.

## Components

- **PracticeScreen.tsx** — Main practice view (exercise display, recording, results)
- **PracticeControls.tsx** — Control buttons (play, record, analyse, retry)
- **PracticeNote.tsx** — Display notes or feedback

## Purpose

Renders the primary learning experience: display Swedish exercise, handle playback, recording, and result display.
